Adaptive Multi-Vector Update (Continual Learning)Sistem memperbarui profil wajah secara otomatis jika menemukan perubahan penampilan fisik atau kondisi cahaya yang sah.Batas Vektor: Maksimal 5 vektor per siswa.Kondisi Trigger: 0.38 < Distance <= 0.48.TypeScriptasync function handleAdaptiveLearning(studentId: string, currentVector: Float32Array, distance: number) {
  if (distance > 0.38 && distance <= 0.48) {
    const student = await db.faces.get({ studentId });
    
    // Implementasi batas maksimum (FIFO)
    if (student.embeddings.length >= 5) {
      student.embeddings.shift(); // Hapus vektor tertua
    }
    
    student.embeddings.push(Array.from(currentVector));
    await db.faces.put(student); // Update lokal
    
    // Antre untuk push ke Supabase
    await db.syncQueue.add({
      type: 'VECTOR_UPDATE',
      studentId: studentId,
      newEmbedding: Array.from(currentVector),
      status: 'pending'
    });
  }
}

Deteksi Keburaman (Blur Gate)Mencegah False Rejection akibat gambar yang blur saat siswa bergerak. Sistem menghitung varians warna tepi (Laplacian). Jika di bawah ambang batas ketajaman, frame ditolak sebelum masuk ke AI.Mekanisme: Mengekstrak ImageData dari kanvas, mengubahnya ke matriks grayscale, dan menerapkan Laplacian kernel ([0, 1, 0, 1, -4, 1, 0, 1, 0]).Eksekusi: Jika nilai variance dari matriks tersebut $< 100$ (kategori buram), frame dilewati dan sistem menunggu frame berikutnya di interval 250 ms selanjutnya.
